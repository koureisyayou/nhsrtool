# 農園向け簡易監視システム (Farm Security PWA)

## 📌 概要

本プロジェクトは、農産物の盗難対策および圃場（ほじょう）の安全管理を目的とした、ブラウザ上で動作する**完全無料・サーバーレス型**の自動カメラ監視システムです。

PWA（Progressive Web App）に対応しており、一度アクセスすれば**山間部などの完全な圏外（オフライン環境）でも起動・稼働**させることができます。

お手持ちの古いスマートフォンやタブレットを再利用し、現地の簡易的な記録ツールとしてご活用ください。

## ✨ 主な特徴

- **完全無料・広告なし:** 外部サーバーへの接続や会員登録は一切不要です。
- **完全ローカル処理:** 撮影された映像やログデータは、端末の内部ストレージ（または指定したフォルダ）にのみ保存されます。プライバシーやインターネット通信量を気にする必要はありません。
- **圏外（オフライン）対応:** キャッシュ機能により、電波の届かない山奥の果樹園でも機内モードのまま動作します。
- **設置チェックモード:** 録画せずにカメラを起動し、**いま何に反応しているかを映像の上に赤く表示**します。設置直後にその場で向きと感度を確かめられるので、「録れているつもりで録れていなかった」を防げます。
- **環境適応型・動体検知:** 雲の影や日照変化など「画面全体の明暗変化」による誤検知を自動で間引くデジタルフィルタを搭載。
- **検知の前後を1本の動画で保存:** 常時バッファに映像を溜めているため、**検知の約15秒前から約15秒後まで**（合計約30秒）を1本のファイルとして書き出します。犯人が映り込む「近づいてくる場面」を取り逃しません。
- **セキュリティログ出力:** 動画書き出し時に、改ざん防止の証拠担保となるSHA-256ハッシュ値をCSVログに自動記録します。さらにCSV全体のハッシュを `security_log.sha256` に出力し、ログ自体の改ざんも検証できます。
- **画面消灯の自動抑止:** 監視中はアプリ側で端末のスリープを抑止します（対応ブラウザのみ）。
- **印刷用告知看板の生成:** 法的明示義務（防犯カメラ作動中などの掲示）を満たすためのA4サイズ告知用画面をワンクリックで生成・印刷できます。

## 📱 ブラウザ対応状況（重要）

本システムはブラウザの最新APIを使用しているため、OSやブラウザによって一部の機能に制限があります。

| 機能 | Chrome (Android) | Edge (Windows) | Safari (iPhone/iOS) |
| :--- | :---: | :---: | :---: |
| **カメラ接続 (入力)** | ○ | ○ | ○ |
| **PWA化 (ホーム画面追加)** | ○ | ○ | ○ |
| **MediaRecorder (動画生成)** | ○ | ○ | △ (iOS14.5以降で対応) |
| **検知前後の映像の結合保存** | ○ | ○ | 🚫 **× (再生できない可能性が高い)** |
| **フォルダ直接固定保存**<br>`showDirectoryPicker()` | **○ (推奨)** | **○ (推奨)** | 🚫 **× (個別ダウンロードになります)** |
| **古い動画の自動削除** | ○ | ○ | 🚫 × |
| **画面消灯の自動抑止**<br>`Screen Wake Lock` | ○ | ○ | △ (iOS16.4以降) |

### ⚠️ iOS (iPhone/iPad) をご利用の方へ

iOS Safariには次の制限があります。**iPhoneでの本格運用は推奨しません。**

- 「フォルダ直接選択API」に対応していないため、動画はフォルダへ自動保存されず、通常のファイルダウンロードとして保存されます。
- 古い動画の自動削除が動作しないため、ストレージが際限なく埋まります。
- 録画形式が `.webm` ではなく `.mp4` になり、**検知前後の映像を結合した動画が正しく再生できない可能性が高い**です。

長期間の完全自動運転を行う場合は、**Android端末、またはWindowsタブレット・PC（Chrome / Edge）**での運用を強く推奨します。

## 🛠️ 必要機材・設置のステップ

1. **スマートフォン / タブレット / PC**（使わなくなった古いAndroidスマホ等が最適）
2. **三脚および固定治具**
3. **大容量モバイルバッテリー または 常時給電環境**

### 使い方

1. `https://` でページを開きます（GitHub Pagesなど）。
2. 「保存フォルダを選択する」で書き出し先を指定します（Chrome / Edge のみ）。
3. 複数のカメラから選びたい場合のみ「カメラ一覧を取得する」を押します。何もしなければ背面カメラが使われます。
4. 「詳細・再利用設定を表示する」から、作物名・設置場所・検知感度・タイマー時間帯などを設定します。設定は端末に自動保存され、次回も引き継がれます。
5. カメラを設置したら、**まず「🎯 設置チェック」で向きと感度を確かめます**（次項参照）。
6. 「チェックを終わる」を押し、「監視スタート」で運用を開始します。約15秒の映像安定化のあと監視が始まります。

## 🎯 設置チェックモードの使い方（最初に必ず）

市販の防犯カメラと違い、本システムは設置の良し悪しを誰も教えてくれません。**感度を勘で決めると、翌日に空振り動画が数百本たまっているか、逆に何も録れていないかのどちらかになります。** それを防ぐための機能です。

「🎯 設置チェック」を押すとカメラが起動し、**録画は行わずに**検知の様子だけを表示します。反応したマスが映像の上に赤く重なるので、どこで反応するかが目で見えます。

画面に出る数字と文字の意味:

| 表示 | 見方 |
| :--- | :--- |
| **いま反応しているマス** | 現在検知されている変化の量。右の「録画が始まるライン」に届くと録画対象になります |
| **この30秒で録画が始まった回数** | 誤検知の目安。**誰も通っていないのにこれが増えるなら感度が高すぎます** |
| 🟢 静かです | 変化なし。この状態が基準です |
| ⚡ 反応しかけています | ラインに届いたが、まだ録画開始には至っていない状態 |
| 🚨 反応中 | この動きなら実際に録画が始まります |
| 🌤 画面全体の明暗変化 | 雲や日射による全体変化と判断し、録画しません（誤検知フィルタが働いている状態） |

### 調整の手順

1. 侵入されそうな経路を実際に歩いてみる → **🚨 が出れば向きはOK**。出ないなら感度を上げる、またはカメラを近づける
2. その場を離れて30秒ほど放置する → **回数が0のままなら誤検知なし**。増えるなら感度を1段下げてもう一度
3. 感度はパネル内のセレクトでその場で切り替えられます。変更は本体の設定にも保存されるので、そのまま「監視スタート」に進めます

判定の条件は本番の監視モードとまったく同一です。チェックで反応しなかった動きは本番でも反応しません。

### ⚙️ 現場運用の注意点

- **HTTPS接続が必須:** カメラAPIのセキュリティ仕様上、本システムは `https://`（GitHub Pagesなど）または `localhost` 環境以外ではカメラが起動しません。
- **画面スリープについて:** 監視中はアプリが自動で画面消灯を抑止します（詳細設定パネルの「画面消灯の抑止」欄で状態を確認できます）。ただし**ブラウザを裏に回したり別アプリに切り替えると監視は止まります**。非対応と表示された端末では、従来どおり端末設定で「画面消灯時間：なし」にしてください。
- **端末そのものの盗難対策:** **スマホごと持ち去られると、映像も一緒に失われます。** 手の届かない高さ、物陰、または屋内から窓越しに撮るなど、端末自体が見つかりにくい位置に設置してください。目立つ位置にはダミーのカメラや告知看板を置き、実機は別の場所に隠すのが有効です。
- **設置後の生存確認:** ブラウザが落ちたり端末が再起動すると監視は止まりますが、通知は届きません。畑に行くたびに画面が「📷 監視システム稼働中」のままかを確認する習慣をつけてください。
- **発熱・熱暴走対策:** ハウス内や直射日光下ではスマホが非常に高温になります。日よけの設置や、夜間のみ稼働する「タイマー運転機能」を活用してください。「簡易発熱警戒モード」は処理遅延が3回続いたときに1分間の自動冷却休止に入ります。
- **設定の複製:** 複数台を同じ設定で運用する場合は、「設定をファイルに書き出す(JSON)」で保存し、別端末で読み込んでください。

## 📂 保存されるファイル

| ファイル | 内容 |
| :--- | :--- |
| `CRIME_日付_時刻_作物名_設置場所.webm` | 検知の前後約30秒を1本にまとめた動画 |
| `security_log.csv` | 発生日時・作物・場所・ファイル名・サイズ・SHA-256ハッシュの記録 |
| `security_log.sha256` | CSV全体のハッシュ値（ログ自体の改ざん検証用） |

動画ファイルは「最大保存ファイル数制限」を超えると古いものから自動削除されます（Chrome / Edge のみ）。CSVとハッシュファイルは削除されません。

## 🎬 動画ファイル再生について

保存される動画は主に `.webm` 形式です。Windowsの古い標準プレイヤー（Media Player）等では再生できない場合があります。その場合は以下の方法で再生してください。

- **Google Chrome / Microsoft Edge** などのブラウザに動画ファイルをドラッグ＆ドロップする。
- **VLCメディアプレイヤー**（無料・マルチプラットフォーム対応）などの互換プレイヤーを使用する。

なお、シーク（早送り・巻き戻し）が効かない場合があります。これは録画中のデータをそのまま書き出す方式のためで、映像自体は最初から最後まで再生できます。
